# Run the Student Companion

The **SaNDAI AI Career Lab** guides participants through Reflect → Practice → Check → Build → Plan. Start with the example inputs or replace them with your responses. No management data or paid AI service is needed.

## Fastest route: Google Colab

1. Open the [student companion directly in Colab](https://colab.research.google.com/github/pzg8794/sandai-seminar-operations-demo/blob/main/notebooks/Piter_Garcia_SaNDAI_Student_Seminar_Companion.ipynb).
2. Choose **Runtime -> Run all**.
3. Choose a visual, quick-guide, or talk-then-write entry route.
4. Change the form fields and run each step to build your own practice record and next action.

## Local route: VS Code

1. Clone the repository.
2. Open [`SaNDAI.code-workspace`](../SaNDAI.code-workspace).
3. On the configured Mac, the environment is already installed. On another machine, run `SaNDAI: Bootstrap local environment`.
4. Open [`Piter_Garcia_SaNDAI_Student_Seminar_Companion.ipynb`](../notebooks/Piter_Garcia_SaNDAI_Student_Seminar_Companion.ipynb).
5. Select the project `.venv` Python kernel and choose **Run All**.

## What to test

The companion helps participants:

- complete a career-readiness self-check;
- choose a comfortable entry route and recover their place through visible step cues;
- practice **Ask -> Check -> Choose -> Change -> Explain** with a prompt;
- receive immediate, supportive feedback on the completeness of their review;
- plan credential/resume evidence;
- build one small weekly action plan;
- produce an outcome card with a concrete next step.

## What success looks like

- every cell runs without a secret key or paid API;
- no management or Shared-drive data is requested;
- the end of the notebook produces a concrete next step rather than a generic AI response.
